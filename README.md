# egor-xyz

A little corner of the open web — my personal homepage, built to live on the [AT Protocol](https://atproto.com) (the network behind Bluesky). Data in my own repo, no lock-in, portable forever.

## What's here

- `test.html` — the homepage. Warm editorial vibe: cream paper, espresso ink, amber→sienna→berry accents, Fraunces + Newsreader + Space Mono, grain texture, staggered load-in.

## Run it

```bash
open test.html
```

No build step — it's a single self-contained file.

## Stack

- Plain HTML/CSS, zero dependencies
- Google Fonts (Fraunces, Newsreader, Space Mono)
- Respects `prefers-reduced-motion`
